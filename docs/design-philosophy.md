# The Field Chart: Design Philosophy

Re-Encoded Vocabulary is a translation instrument disguised as a field manual.
It should feel consulted, not scrolled; precise, not sterile; personal, not
arbitrary. The interface exists to help a learner move an idea from unfamiliar
territory into a mental model they already own.

## Core principles

### Translate the mechanism before decorating it

Every lens must preserve the underlying relationship, sequence, constraint, or
failure mode of the concept. A metaphor that is memorable but technically
wrong is a bug in the teaching system.

### Make the page feel like a working reference

The visual language should suggest a well-used chart, field guide, or reference
manual: paper-like surfaces, strong labels, deliberate annotations, and clear
hierarchy. It should reward returning to the same term several times.

### Treat lenses as instruments, not skins

Medical, Sports, Pop Fantasy, Tabletop Games, Culinary, Pop Culture,
Motorsport, and Video Games are parallel ways of thinking. A lens is selected
because it changes comprehension, not because it adds decoration. Lens color and
iconography may orient the learner, but meaning must never depend on color or
emoji alone.

### Let depth arrive in stages

The first view should answer “what is this?” The next should answer “how does
it work?” The next should answer “when would I use it?” Progressive disclosure
keeps the grid scannable while allowing Study Mode and future learning paths to
be richer.

### Use transformation as the signature interaction

Flipping, translating, comparing, and re-encoding should feel like revealing a
second face of the same object. Motion marks a change in understanding; it is
not ambient entertainment. Every animation must have a reduced-motion form.

### Prefer disciplined character over visual noise

Distinctiveness comes from the combination of editorial voice, field-manual
structure, restrained color, serif display typography, monospace metadata, and
the lens system. Avoid generic dashboard gradients, decorative illustrations
that compete with the term, and gamification that rewards clicks instead of
recall.

### Accessibility is part of the aesthetic

Clear focus, readable contrast, keyboard operation, semantic states, sensible
touch targets, and respectful motion are not an alternate version of the
design. They are what make the reference instrument dependable.

## Visual grammar

| Element | Rule |
| --- | --- |
| Page surface | Warm paper in light mode; deep green-black paper in dark mode |
| Primary ink | Forest/ink tones with strong contrast and calm hierarchy |
| Accent colors | Amber, teal, rose, slate, plum, and clay identify semantic roles |
| Display type | Serif for titles and term names; it should feel editorial and durable |
| Utility type | Monospace for tags, counts, code, progress, and system labels |
| Surfaces | Cards should feel like instruments or chart plates, not generic tiles |
| Motion | Reveal, flip, and transition only when they communicate state change |
| Controls | Compact, labeled, high-contrast, and consistent across modes |

## Analogy writing standard

An analogy should:

1. Name the familiar situation.
2. Preserve the important mechanism.
3. Make the correspondence obvious without explaining the metaphor afterward.
4. Avoid stereotypes, needless lore, and references that obscure the lesson.
5. Stay short enough to compare with the other selected lenses.

## Review checklist

Before merging a new surface, term, lens, or animation, ask:

- Does this make the concept easier to orient to or remember?
- Does the visual treatment communicate state, relationship, or provenance?
- Does the content remain accurate when translated through the chosen lens?
- Can a keyboard and screen-reader user complete the same task?
- Does it work in both themes, at narrow widths, and with reduced motion?
- Would the addition still feel at home in a field manual five years from now?
